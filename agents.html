填写最小项目上下文，生成一条可以直接粘贴到 Codex 的启动指令。页面不会自动创建线程或开始编排。

Agent 会先读取这个范围内的项目说明和约束。

默认边界：先只读了解项目；不自动创建线程、不自动增加 Agent、不扩大范围；涉及发布、生产、数据库、密钥或删除时，必须由用户另行明确授权。

浏览器未允许自动复制时，可在这里手动复制。

使用边界：这张页面只负责介绍 Agent 和提供启动指令。它不读取项目 Run、不显示谁正在做什么，也不自动分配任务。

项目映射：具体项目中的 A01、A02 等稳定身份，以项目自己的 `TEAM.yaml` 和角色文件为准；本页是通用角色入口。
