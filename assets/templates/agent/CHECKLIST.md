# Agent 检查清单

## 任务开始前

- [ ] 读取任务文件，理解目标
- [ ] 检查依赖是否满足
- [ ] 检查写入域是否冲突
- [ ] 确认验收命令
- [ ] 检查实际文件状态

## 任务执行中

- [ ] 只修改允许范围内的文件
- [ ] 保留真实命令和结果
- [ ] 记录错误和失败尝试
- [ ] 发现跨域问题时停止
- [ ] 产物保存到指定目录

## 任务完成后

- [ ] 生成标准交接文档
- [ ] 同步完整对话（如需要）
- [ ] 更新当前上下文
- [ ] 创建检查点（如需要）
- [ ] 更新索引

## 交接检查

- [ ] 状态合法（completed/blocked/failed，与 Protocol v3 一致）
- [ ] 修改文件清单完整
- [ ] 命令来自真实执行
- [ ] 结果不是主观描述
- [ ] 风险和未完成项未隐藏
- [ ] 产物路径存在
- [ ] 没有越界修改
